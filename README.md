# 🎁 Giftly
### Making Every Gift Feel Special

**Giftly** is an online gift shopping platform designed to make finding and sharing meaningful gifts easier. Customers can explore products, manage their accounts, and complete purchases through a simple shopping experience.

---

## ✨ Features

- 🛍️ **Product Shopping** Browse and explore available gifts.
- 👤 **Customer Accounts** Register, log in, and manage personal profiles.
- 🛒 **Shopping Cart** Add and manage selected products.
- 💳 **Checkout** Complete the purchasing process.
- 🎀 **Gift Discovery** Find suitable gifts for different occasions.
- 🤖 **AI Gift Assistant** Get assistance with gift recommendations.
- 📦 **Order Management** Manage customer orders.
- 🔐 **Admin Dashboard** Manage products, customers, and store activities.

## 🚀 Getting Started

### Requirements

- XAMPP
- PHP
- MySQL
- Web browser
- Git (optional)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/raicha2027/Giftly.git
```

**2. Move the project**

Place the Giftly folder inside your XAMPP `htdocs` directory.

**3. Start XAMPP**

Start:
- Apache
- MySQL

**4. Set up the database**

- Open `http://localhost/phpmyadmin`
- Create a database named `giftly`.
- Import the `giftly.sql` file.

**5. Configure the database**

Check the database connection settings in the configuration files and update them to match your local MySQL environment.

Do not publish private production credentials.

**6. Open Giftly**

Visit:

```text
http://localhost/Giftly/
```
